# Password Generator

A Python program that generates personalized password wordlists based on user-provided information.

## Features

- Generates personalized password combinations
- Supports first name and last name
- Supports date and year of birth
- Supports phone numbers
- Supports custom text
- Supports symbols
- Removes duplicate passwords
- Allows minimum and maximum password length
- Saves generated passwords to a text file

## Requirements

- Python 3

No external Python libraries are required.

## Usage

Run the program with:

```bash
python3 password_generator.py
